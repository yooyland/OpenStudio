# YooY AI Studio 12.9.0 — Gallery + Projects Continuity

## Summary

Phase 5 connects Generate → Gallery → Remix → Project → Continue into one creative flow. Gallery remains the canonical asset store; Projects only reference Gallery IDs.

## Requirements

- WordPress 6.x
- PHP 7.4+

## Install

1. Upload `yooy-ai-studio-12.9.0-gallery-projects-ux.zip`
2. Activate **YooY AI Studio**
3. Open Studio shell / Home

## Changes

- Large Gallery portfolio cards, single hover Remix CTA, ⋯ secondary actions
- Consistent asset detail preview with lineage/related works when known
- Gallery search/sort/filters (title, prompt, type)
- Project creative cards + continue working; simple name-only create
- Add-to-project without asset duplication; already-linked message
- Active Project context on Studio generate payloads
- Simplified Image result actions
- History timeline mode (not a second Gallery)
- Public Works feed strips private generation metadata

## Package

`yooy-ai-studio-12.9.0-gallery-projects-ux.zip`
