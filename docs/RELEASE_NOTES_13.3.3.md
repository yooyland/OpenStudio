# Release Notes — 13.3.3

**YooY AI Studio** — Top-right header simplification

## Changes

- Authenticated top-right header reduced to **Profile / MY** dropdown + **Notifications** bell
- Removed standalone Credits pill, Plan pill, Help/Theme icons, gold crystal, and Section Management from the top bar
- Plan and credits summary live inside the MY menu header; destinations reuse existing Settings / Credits routes
- Admin tools remain in MY → 관리자 도구 and the left sidebar (not in the header)

## Install

1. Upload / replace `yooy-ai-studio/` plugin folder (or ZIP)
2. Hard-refresh Creator OS assets (`?ver=13.3.3`)

## Requirements

- WordPress 6.x
- PHP 7.4+
